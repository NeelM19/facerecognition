# Face Attendance

On-device face recognition attendance app built with Flutter.

## Face recognition

See **[docs/FACE_RECOGNITION_IMPLEMENTATION.md](docs/FACE_RECOGNITION_IMPLEMENTATION.md)** for:

- Models used (**BlazeFace**, **MediaPipe Face Mesh**, **MobileFaceNet**)
- Enrollment and punch pipelines
- Matching thresholds and local storage

## Getting started

```bash
flutter pub get
flutter run
```

Requires camera permission on device/emulator.
